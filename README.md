# Simple To-Do List App. An assignment for RevoU Coding Camp

A simple to-do list app built with HTML, CSS, and JavaScript.

## RevoU Suggested Workflow

1. Design is only reference, you can improve for your own design but you must have the feature :
  - Form To-Do and Date Input
  - Display To-Do List
  - Add, Filter, and Delete
2. Validate Input Form
3. Put css file inside of the css/ folder
4. Please only put only 1 css for the entirety of the project
5. Put javascript files inside the js/ folder
6. Please put only 1 javascript file for the entirety of the project
7. After finish your website, upload the Source Code in GitHub Classroom and publish the website in Github Pages
8. Submit URL repository and published website through dedicated Paperform submission that will be opened on Thursday
